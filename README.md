# petrus' core utilities

This is a project that aims to clone most of the main GNU core utilities.
It's educational purpose for me to learn more about the C language.

I try not to use AI for helping with this project, but sometimes I use it to
explain me some functions, behaviors and program's flow, or to understand the
difference between some functions... and to make this Makefile :(

## Installing

```bash
make install
```

## Uninstalling

```bash
make uninstall
```

## Cleaning

```bash
make clean
```
